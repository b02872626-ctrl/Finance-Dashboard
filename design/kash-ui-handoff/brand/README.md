# Kash app icon

- `app-icon.svg`: full icon (slate background #3D4859 + bars). Use for previews and the Play Store listing.
- `app-icon-foreground.svg`: bars only, 108×108 with the bars inside the 66dp safe zone. Adaptive icon foreground; background colour #3D4859. Also the splash-screen icon on #3D4859.
- `app-icon-monochrome.svg`: one-colour version for Android 13+ themed icons.
- Small notification icon: use the foreground bars as a white silhouette.
