The 4-digit PIN dots and keypad, used on Create a PIN, Unlock and Change PIN. Always on slate.

**You provide:** `filled` (digits entered), `length` (4), `message` (an error such as "PINs didn't match. Start again."), `disabled` (during a lockout), `onDigit` and `onDelete`.

- Filled dots are white, empty ones are rings. Sand is not used here.
- During a lockout the keypad fades and a countdown chip replaces the message.
