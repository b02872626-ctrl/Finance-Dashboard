# Flow Diagrams

- `app-entry-auth-flow.*` — app launch, permission gate, sign-in gate, onboarding, and shell entry
- `sms-ingest-dedupe-flow.*` — SMS read pipeline, raw capture, dedupe, parse, and local persistence
- `parser-routing-flow.*` — parser priority order and receipt-link fallback
- `supabase-sync-flow.*` — local queue, WorkManager sync, retries, notifications, and Supabase upload

Each flow is saved as Mermaid source (`.mmd`), PNG (`.png`), and JPEG (`.jpg`).
